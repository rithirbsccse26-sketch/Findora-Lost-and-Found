# Findora-Lost-and-Found
A web-based platform that helps people report lost belongings, share found items and connect with others to recover their belongings.
About the Project

Findora is designed to make the process of finding lost belongings easier. Users can create accounts, report lost or found items, browse listings and contact other users.

Technologies Used
- HTML – Website structure
- CSS – Website styling and layout
- PHP – Backend functionality
- JSON – Storing user and item information
- XAMPP – Local development environment
Features
- User registration and login
- Dashboard with community statistics
- Combined Report Lost / Found form
- Browse and search items
- Category filters
- Contact and messaging feature
- Saved items
- My Reports
- Mark items as Returned
How to Run
1. Install XAMPP.
2. Copy the project folder into htdocs.
3. Start Apache.
4. Open http://localhost/Findora/.
Project Purpose

Findora aims to make lost-and-found services more accessible through a simple online community.
